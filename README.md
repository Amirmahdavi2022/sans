# 🎬 سانس | Sans

بات و مینی‌اپ تلگرام برای پیدا کردن فیلم و سریال. اینجا فیلم پخش نمیشه، فقط کمکت میکنه بفهمی چی ببینی.

**بات:** [@SansGuideBot](https://t.me/SansGuideBot)

## چی داره

- **خانه:** ترندهای امروز، تازه‌های سینما، سریال‌هایی که الان پخش میشن، برترین‌ها
- **امشب چی ببینم؟** سه تا سؤال میپرسه (فیلم یا سریال، حال‌وهوات، چقدر وقت داری) و بعد پیشنهادها رو کارت‌کارت نشون میده. به راست بکشی میره تو لیستت، به چپ بکشی میره بعدی
- **صفحه‌ی هر فیلم و سریال:** امتیاز، خلاصه، بازیگرها، تریلر، فصل‌ها و قسمت‌ها، و چندتا پیشنهاد شبیهش
- **لیست من:** «می‌خوام ببینم»، «دیدم» و سریال‌هایی که دنبال میکنی
- **خبرم کن:** وقتی قسمت جدید سریالی که دنبال میکنی بیاد، بات بهت پیام میده
- **جستجو** با اسم فارسی یا انگلیسی، و گشتن بر اساس ژانر
- اسم یه فیلم رو تو خود بات هم بفرستی پیداش میکنه
- **فارسی و انگلیسی**، با یه دکمه عوض میشه
- برای استفاده باید عضو کانال [@parsv2r](https://t.me/parsv2r) باشی

## چطوری کار میکنه

همه‌ش یه Cloudflare Worker هست. خود مینی‌اپ، API، پروکسی عکس‌ها، وبهوک بات و چک ساعتی قسمت‌های جدید همه همونجان. لیست‌ها تو D1 ذخیره میشن.

کاربر هیچ وقت مستقیم به TMDB یا telegram.org وصل نمیشه و همه چی از دامنه‌ی خود سانس رد میشه، چون اونا تو ایران خیلی وقتا باز نمیشن. فونت (وزیرمتن) هم تو خود Worker هست.

```
src/worker.js    مسیرها، API، پروکسی عکس
src/tmdb.js      گرفتن و مرتب کردن داده از TMDB
src/telegram.js  چک کردن initData، Bot API، چک عضویت کانال
src/bot.js       /start، دکمه‌ی عضو شدم، جستجو تو بات
src/alerts.js    چک ساعتی قسمت جدید
src/app.html     خود مینی‌اپ
```

## تست

```
npm install
npm test
```

یه سرور ساختگی جای TMDB و تلگرام بالا میاد، Worker با `wrangler dev` اجرا میشه و همه‌ی مسیرها تست میشن (ورود، عضویت کانال، لیست‌ها، بات، پیام قسمت جدید).

## دیپلوی

با هر push روی `main` اکشن اول تست‌ها رو میزنه و بعد دیپلوی میکنه. این سه تا سکرت تو تنظیمات ریپو لازمه:

| سکرت | چیه |
| --- | --- |
| `CF_API_TOKEN` | توکن کلادفلر اکانتی که `ctrjmc.xyz` روشه |
| `TMDB_KEY` | API Key از TMDB |
| `BOT_TOKEN` | توکن بات از BotFather |

گزارش هر اجرا میره رو برنچ `ci-logs`.
